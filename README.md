# Rock Paper Scissors

A browser-based Rock Paper Scissors game built with HTML, CSS, and vanilla JavaScript as part of [The Odin Project](https://www.theodinproject.com/paths/foundations/courses/foundations) Foundations curriculum.

## Live Demo

[Play Rock Paper Scissors](https://alPuneeth.github.io/Rock-Paper-Scissors/)

## Features

- Play Rock, Paper, Scissors against the computer.
- Randomized computer choices.
- First to 5 points wins.
- Live score tracking for both players.
- Custom yin-yang visualization that changes with the score difference.
- Round-by-round results and a final game result.
- Win animation when the game ends.
- Reset button to start a new game.
- Interactive button hover effects.

## Built With

- **HTML5** — Page structure and game elements.
- **CSS3** — Layout, styling, yin-yang visualization, and animations.
- **JavaScript (ES6+)** — Game logic, DOM manipulation, event handling, and score tracking.

## Getting Started

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/alPuneeth/Rock-Paper-Scissors.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Rock-Paper-Scissors
   ```

3. Open `index.html` in a browser, or use the Live Server extension in VS Code.

No dependencies or build tools are required.
